# SuperStore_Sales_Analytics_Dashboard
A sales dashboard in PowerBI, with useful data for Sales Stores
Creation of a dashboard using a public dataset from Michael Martin at tableau website as reposted by Vivek Chowdhuty at Kaggle,  of an international superstore selling various products across the globe. Focused on client analytics, market analytics and even shipping analytics using PowerBI. Dashboard created by: Michalis Fessas and Alexandros Papalexandris
